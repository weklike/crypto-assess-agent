# 150条候选检索问题的使用说明

本文件是标注准备，不是gold标注。候选JSONL七个字段与用户方案一致，文件名故意不使用正式v1；所有gold_refs为空，level为空。150条含50个主题的三种表达，100%由模型合成。不能写成“收集150条真实用户问题”。

## 操作流程

把候选CSV留在研究/标注工作区，先不复制到正式eval/datasets目录。所有者打开真实条款库，对每条核查能否回答、层面是否准确、等级是否需要明确；“paraphrase”仅是任务改写候选，需重新核对是否忠实于原文。

建议将四路检索结果合成待查候选池，再查相关父条款、其他层面和测评说明，选全相关gold。每条记录完整引用、选择理由和复核人。不要从本文件推导任何标准章号。最后按现有标注工具的真实接口追加进入正式数据集，运行validator，再抽查10条。

同一IG主题组的三个问句应放在同一数据划分中，防止同义问题跨开发集和测试集。主题组ID在provenance.json中，不改变正式数据集schema。

## 检索扩展词表（候选，不是可直接投产的同义词规则）

| 用户常用说法 | 可一起检索的术语 | 不能直接等同的内容 |
|---|---|---|
| 密评 | 商用密码应用安全性评估 | 不等于等保测评 |
| 密改、国密改造 | 密码应用方案、算法/产品改造 | 不等于已经通过评估 |
| UKey、USBKey | 智能密码钥匙、身份凭据 | 不保证认证证书有效或实际使用正确 |
| VPN、加密隧道 | 通信身份鉴别、机密性、完整性 | 不保证所有链路覆盖 |
| SSL、TLS、HTTPS | 协议版本、协商套件、证书校验 | 不等于国密套件已启用 |
| 双证书 | 签名证书、加密证书、密钥用途 | 不能忽略使用场景和协议 |
| 签名验签 | 数字签名、真实性、完整性 | 不等于贴章图片或密码加密 |
| 防抵赖、抗抵赖 | 不可否认性、业务证据 | 不等于任何日志都能支撑 |
| 杂凑、哈希、hash | 摘要、完整性相关机制 | 单独摘要不保证可信来源 |
| MAC、消息认证码 | 带密钥的完整性/认证机制 | 不等于普通摘要，也不提供对第三方的签名证明 |
| TDE、透明加密 | 数据库存储机密性、访问威胁 | 不保证数据库运行态全部风险都被覆盖 |
| KMS | 密钥管理系统、密钥生命周期 | 名称不保证完整实现 |
| HSM | 密码模块、密码设备 | 不与任何服务器密码机型号无条件等同 |
| 硬编码、写死密钥 | 密钥存储、访问权限、导出风险 | 要结合具体暴露条件 |
| 堡垒机、跳板机 | 运维身份鉴别、远程管理通道 | 不能忽略最后一跳 |
| 日志防篡改 | 日志完整性、留存、验证依据 | 不等于只读权限或集中存储 |
| 证书吊销 | 撤销状态、信任失效 | 不等于证书过期 |
| 密钥轮换 | 更新、版本、历史数据处理 | 不等于直接覆盖旧密钥 |
| 容灾、恢复 | 密钥备份恢复、业务连续性 | 不等于已有密码应急证据 |
| 不适用 | 需求和方案论证、适用范围 | 不等于未知、没材料或没有部署 |

以上是本次建议的检索联想，不是已核验的全部标准术语定义。正式词典应根据实际误检和漏检再决定，避免误把相关词配置成完全等价。

## 标注质量复核

记录未标注、已标注待审、已确认三种状态；空gold不能用于表示正式负样本。对于组合问题，例如数据库加密同时问密钥管理，应检查是否需要多个gold。对不能由当前两份标准支撑的问题，明确拒收或纳入独立的语料外校准集；不能为凑150条编造引用。

本次只做文件结构校验，未对任何gold作正确性验收，也未运行项目的RetrievalDatasetValidator。
